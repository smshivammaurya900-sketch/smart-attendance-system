# Smart Attendance System 📋

A lightweight, command-line **Smart Attendance Management System** built in Python for **BCA IBM (United University)** students to streamline daily attendance tracking and reporting.

## ✨ Features
- **Quick Attendance Marking:** Mark students as Present (`P`) or Absent (`A`) interactively.
- **Full Attendance Report:** View the complete attendance status of all students in one place.
- **Absentee Filter:** Quickly filter and list only absent students along with the total absentee count.
- **Input Validation:** Handles case-insensitive inputs and prevents viewing empty reports before marking attendance.

## 🛠️ Tech Stack
- **Language:** Python 3
- **Core Concepts Used:** Functions (`def`), Dictionaries, Lists, List Comprehensions, and Loops.
